# AI-Augmented Data Engineering Roadmap

> Core knowledge is not removed. It is solidified first. AI is then added in the right places to augment, not replace, the data engineering workflow.

This platform is designed as a learning system, not just a list of tutorials. Each phase builds the foundation for the next phase, and each project reuses the output of the previous project.

## How to use this site

1. Follow the roadmap by phase.
2. Open skills when a project requires a specific concept.
3. Build projects in dependency order.
4. Add notes, diagrams, and code snippets as Markdown.

## Performance model

Markdown files are compiled once at build time into static HTML. The browser only loads the current page, plus a small static search index.
