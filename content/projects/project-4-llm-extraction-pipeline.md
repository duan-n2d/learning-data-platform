# Project 4 - LLM Extraction Pipeline

## Goal

Extract structured records from PDFs, emails, text files, and semi-structured notes.

## Pipeline

```txt
Unstructured source
→ preprocessing
→ LLM extraction
→ schema validation
→ human review queue
→ warehouse table
```

## Deliverables

- Extraction schema
- Parser job
- Validation layer
- Error queue
- Review report
