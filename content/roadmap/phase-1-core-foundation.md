# Phase 1 - Core Foundation

Phase 1 is about becoming technically solid before relying on AI. AI can speed up coding, but it cannot replace your understanding of data quality, modeling, orchestration, and debugging.

## Focus areas

| Area | Outcome |
|---|---|
| SQL Advanced | Window functions, CTEs, query optimization, analytical patterns |
| Python | File processing, API calls, data validation, automation scripts |
| dbt | Staging, marts, tests, documentation, lineage |
| Airflow | DAG design, retries, dependencies, scheduling |
| Cloud | Object storage, managed database, basic IAM, deployment |

## Deliverable

Build Project 1: Core Analytics Warehouse.
